# Fixture Sources

Use these sources for Phase 4 once their licenses are checked in detail:

- Git test suite: patch parsing, rename, mode, merge, and conflict fixtures.
- GNU diffutils: traditional unified/context diff edge cases.
- libgit2: repository status and merge fixtures.
- diff-match-patch / dissimilar: intraline and human-readable cleanup cases.
- tree-sitter grammars: syntax-highlight visible-range fixtures.

Imported fixtures should preserve attribution and original license text.
