# Office Document Diffing — Research & Approach Comparison

## Summary

This folder captures research on diffing Office Open XML (OOXML) documents
(.docx, .pptx, .xlsx). Three approaches were researched, implemented as
prototypes, and compared against real reference `.docx` files.

The reference files are generated programmatically (see `common/mod.rs` in
the test suite) and exercise:
- Simple text changes (paragraph content)
- Multi-paragraph documents with additions/deletions
- Mixed formatting (bold, italic within a paragraph)
- Tables with changed cell content
- Tracked changes (ins/del marks) in the XML

## Three Approaches

| # | Approach | File | Description |
|---|----------|------|-------------|
| 1 | **Convert-to-text** | `word/extract.rs` | Extract all text from XML, flatten to lines, use `diff-core` |
| 2 | **XML tree comparison** | `word/xml_diff.rs` | Compare XML element trees structurally |
| 3 | **Semantic model** | `word/compare.rs` | Parse into `WordDocument`, compare model objects |

## Quick Verdict

| Approach | Content Changes | Formatting Changes | Structure Changes | Complexity | Speed |
|----------|----------------|--------------------|--------------------|------------|-------|
| 1. Text extraction | ✅ Good | ❌ Invisible | ❌ Lost | Low | Fast |
| 2. XML tree diff | ✅ Over-sensitive | ✅ Detects | ✅ Detects | Medium | Medium |
| 3. Semantic model | ✅ Best | ✅ Best | ✅ Best | High | Medium |

**Recommendation:** Use Approach 3 (semantic model) as the primary engine,
falling back to Approach 1 (text extraction) as a quick-preview mode.
Approach 2 is useful for debugging and validating the semantic parser.

## Reference Files

The `reference-examples/` directory contains `.docx` files with varied content.
They are generated by `cargo test -p office-adapter -- --nocapture`
from the test helper generators in `tests/common/mod.rs`.

Key examples:
- `text-change.docx` — Simple paragraph text replacement
- `formatting-change.docx` — Bold→Normal conversion without text change
- `multi-paragraph.docx` — Multiple paragraphs, some added/deleted
- `table-data.docx` — Table with cell-level changes
- `tracked-changes.docx` — Document with existing tracked changes in XML
